# ステラ シェアソーシング：買取・販売数量の決定

シェアソーシング契約企業からの買取と、契約企業への卸販売の商品・数量を判断し、確定した取引から明細の下書きまで作成するスキルです。

## ファイル

- [SKILL.md](SKILL.md)：スキル本体。買戻し条件、実行手順、途中再開と二重登録防止。
- [全社在庫・仕入れ／卸の選定・100日予測](references/inventory-planning.md)：全契約先の在庫照合、追加仕入れ数量、会社別の買戻し不足アラート。
- [請求・支払明細](references/billing-details.md)：確定数量・単価の引継ぎ、明細作成と照合。

利用する際は、SKILL.mdとreferencesフォルダを同じ構成で配置してください。スキルの識別名は既存の `kaimodoshi` を維持しています。

## 主なルール

- 契約企業の保有開始から100日以内にステラが全数を買い戻す。最終顧客への販売完了期限とは区別する。
- 通常の買戻しは自社在庫が1ヶ月分以下のとき、合計2ヶ月分まで補充。売れ行きが50％以上落ちた場合等は合計1ヶ月分まで。
- 月の比較には終了した月を使い、月途中の累計と前月全体を比較しない。
- 安定商品の新規仕入れは全体6ヶ月分を目標候補とし、自社・他社・確定発注済みの在庫を差し引く。採算、回転、買戻し資金も確認する。
- 100日までの全数買戻しが難しい見込みなら、期限前に不足数・必要資金・対応案を報告する。
- 販売は請求明細、買取は支払明細の下書き。正式発行・送付・支払は依頼範囲を別途確認する。

## 運用準備と確認範囲

Google Sheets、GoQ、必要なKeepaデータへのアクセスと、正式な送料・作業料、取引条件、帳票形式が必要です。料金が不明な商品は採算を確定しません。新規仕入れの採算・販売可否は `ec-purchase-decision` または正式な仕入判定手順と併用します。

このリポジトリへの保存だけでは定期監視・自動通知は開始しません。スキルは作業手順であり、外部サービス接続や実取引を自動で実行するプログラムではありません。

最新版は2026年9月30日の会話で合意した内容を反映。元スキルによる1社の模擬確認と、改訂ルールの机上確認を実施済みです。最新版による全社実データでの再検証、正式帳票の発行・送付は未実施です。
